# Realm Wars

"Realmshold: The Frontier War," a complete real-time strategy game in a single HTML file. The stone-and-steel Aldenmoor Legion takes on the bone-and-timber Skarn Clan.

![Realm Wars screenshot](<Realm Wars - screenshot.png>)

## What's in it

- Gather gold and timber, build barracks, farms and watchtowers, train an army and raze the enemy stronghold
- Single-player against an AI that runs several bases and gets tougher over three rounds
- Real multiplayer: one player hosts, a friend joins
- Animated units, a generated soundtrack, and a local high-score table

## Controls

| Input | Action |
|---|---|
| Left-click / drag a box | Select units or buildings |
| Right-click | Move, attack, or (workers) gather |
| WASD / arrow keys | Scroll the map |
| Minimap click | Jump the camera |
| Esc | Cancel placing a building |

## Run it

Download `realm-wars-final-b3.html` and open it in your web browser. No install, no account, nothing to set up.

The full field manual is in `realmshold-manual.pdf`.
